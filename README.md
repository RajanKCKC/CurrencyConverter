# Currency Converter
A small web app that changer one money type into another.

This project lets you type an amount, pick the currency you have, pick the currency you want, and then see the converted value.

## Try it

Open the `index.html1 file in your browser.

## How to use it
1. Type how much money you want to change.
2. Pick the currency you are starting with.
3. Pick the currency you want to turn it into.
4. Click the Convert button.
5. See the answer on the screen.

## What it does 
- Converts many different currencies
- Uses live exchange rates
- Easy and quick to use

## Notes
This app uses an online currency API, so it needs internet access to get latest rates.
